# SalesPulse — Executive Revenue Analytics & Cohort Intelligence

Executive enterprise sales intelligence dashboard with ARR/MRR trendlines, regional sales heat distribution, sales rep leaderboard, product category breakdown, and customer acquisition cost KPIs.

## Product Highlights
- **Domain**: Analytics / BI
- **Visual Theme**: Executive Amber & Navy Slate
- **State Persistence**: Browser localStorage & FastAPI microservices
- **Zero-Dependency Web Client**: Works seamlessly on GitHub Pages

## Architecture & Quick Start
```bash
# Run Tests
pytest tests/

# Docker Deployment
docker-compose up -d --build
```
